# Smart Blind Stick with GPS, GSM and Voice Assistant

## 📌 Project Overview

The Smart Blind Stick is an assistive device designed to help visually impaired people detect obstacles and improve their safety while walking.

The system combines obstacle detection, GPS location tracking, GSM communication, and voice assistance to provide a smart and user-friendly solution.

## 🎯 Objectives

- Detect obstacles in front of the user.
- Provide alerts when an obstacle is detected.
- Track the user's location using GPS.
- Send the location to a predefined contact using GSM.
- Provide voice-based assistance.
- Improve the safety and mobility of visually impaired users.

## ⚙️ Features

- 🔹 Obstacle detection
- 🔹 GPS-based location tracking
- 🔹 GSM-based emergency communication
- 🔹 Voice assistance
- 🔹 Portable and user-friendly design
- 🔹 Real-time alerts

## 🧰 Components Used

- Arduino
- Ultrasonic Sensor
- GPS Module
- GSM Module
- Buzzer
- Speaker
- Battery
- Connecting Wires
- Breadboard / PCB
- Smart Blind Stick Frame

## 🔌 Working Principle

The ultrasonic sensor continuously detects obstacles in front of the user.

When an obstacle comes within a certain distance, the system generates an alert using the buzzer or voice output.

The GPS module obtains the current location of the user. In an emergency situation, the GSM module can be used to send the user's location to a predefined mobile number.

The voice assistance system provides audio feedback to make the device easier to use.
